# MiniShop - Website Bán Hàng & Phụ Kiện Công Nghệ Responsive

Dự án bài tập xây dựng website tĩnh Responsive (08 trang HTML) môn Lập trình Web.

## 1. Thông tin chung
- **Họ và tên:** Trịnh Minh Huy
- **Học phần:** Lập trình Web
- **Đề tài:** Website giới thiệu & phụ kiện công nghệ MiniShop

## 2. Đường dẫn triển khai (GitHub Pages)
- **Website Live:** https://2531540580-svg.github.io/minishop/

## 3. Cấu trúc thư mục (08 trang HTML)
- `index.html`: Trang chủ (Hero banner & sản phẩm tiêu biểu)
- `about.html`: Trang giới thiệu tầm nhìn, giá trị cốt lõi
- `products.html`: Danh mục tất cả sản phẩm
- `details.html`: Trang chi tiết thông số kỹ thuật
- `services.html`: Dịch vụ kỹ thuật (vệ sinh máy, custom phím/chuột)
- `gallery.html`: Bộ sưu tập góc setup trải nghiệm khách hàng
- `blog.html`: Bài viết chia sẻ kinh nghiệm công nghệ
- `contact.html`: Biểu mẫu tiếp nhận yêu cầu & liên hệ
- `css/style.css`: File định dạng Responsive cho Desktop, Tablet và Mobile
- `images/`: Thư mục lưu trữ hình ảnh sản phẩm

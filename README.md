# MiniShop - Website Bán Hàng & Phụ Kiện Công Nghệ

Dự án bài tập xây dựng website tĩnh (Milestone M1) môn Lập trình Web.

## 1. Thông tin chung
- **Họ và tên:** Trịnh Minh Huy
- **Học phần:** Lập trình Web
- **Đề tài:** Website giới thiệu & bán thiết bị công nghệ MiniShop

## 2. Đường dẫn triển khai (GitHub Pages)
- **Website Live:** https://2531540580-svg.github.io/minishop/

## 3. Cấu trúc thư mục
- `index.html`: Trang chủ hiển thị banner và sản phẩm nổi bật
- `products.html`: Danh sách toàn bộ sản phẩm của cửa hàng
- `product-detail.html`: Trang chi tiết thông số kỹ thuật sản phẩm
- `contact.html`: Trang form liên hệ hỗ trợ khách hàng
- `css/style.css`: File định dạng giao diện chung và responsive
- `images/`: Thư mục lưu trữ hình ảnh sản phẩm

## 4. Công nghệ sử dụng
- HTML5 (Cấu trúc ngữ nghĩa header, nav, main, section, footer)
- CSS3 (Flexbox, CSS Grid, Media Queries cho mobile)
- Nguồn hình ảnh: Ảnh minh họa sản phẩm phần cứng/phụ kiện công nghệ
